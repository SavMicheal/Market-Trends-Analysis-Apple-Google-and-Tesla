# Market-Trends-Analysis


## Overview
This project analyzes historical financial data for:
- **Apple (AAPL)**
- **Google (GOOGL)**
- **Tesla (TSLA)**

---

## Dataset
Data was collected using the `yfinance` library from Yahoo Finance. The goal is to explore price trends and volatility among the stocks from 2023 - 2024. The dataset contains 502 rows and 3 columns

---

## Objectives
- Import and clean financial data from Yahoo Finance
- Visualize price trends
- Compare stock volatilities and returns between Apple, Google and Tesla
- Provide insights on market behavior during this period 

---

## Tools & Technologies
- **Python**: Programming language used for analysis.
- **yfinance**: To download stock data from Yahoo Finance.
- **Pandas**: For data manipulation and cleaning.
- **NumPy**: For numerical computations.
- **Matplotlib** & **Seaborn**: For data visualization (static plots).
- **Jupyter Notebook**: For an interactive coding environment.

---

## Data Source
- **Yahoo Finance**
- Tickers:
 -  Apple: `AAPL`
  - Google: `GOOGL`
  - Tesla: `TSLA`
- Date range:  From 1st January 2023 to 31st December 2024

---

## Key Insight For Presentation 

- **Apple (AAPL)**: Apple's distribution is more centered, indicating less price movement compared to tech stocks like Google and Tesla.
- **Tesla (TSLA)**: Tesla stock has a wide spread and is right-skewed, indicating that the mean is greater than both the median and mode. This signifies high volatility and a greater degree of price fluctuation.
- **Google (GOOGL)**: Google stock has a relatively symmetrical distribution, showing fewer extreme outliers, which suggests a more stable trend.
